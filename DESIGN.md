# Grandeur design direction

## Theme
A cinematic hospitality archive: charcoal architectural canvas, bone typography, terracotta signal. Gallery-airy density, asymmetric editorial rhythm, and calm motion.

## Palette
- Charcoal canvas `#101416`
- Slate surface `#151b1d`
- Bone text `#f5f1e9`
- Terracotta accent `#e2a891`
- Muted text `#849093`

## Type
- Display: Fraunces, light, tight tracking, sentence case with restrained italic emphasis.
- Body/UI: Outfit, readable leading, small uppercase labels used only for navigation and metadata.
- Data: system monospace for dates, phases, and coverage labels.

## Layout
Use asymmetric editorial splits, indexed roster rows, image-led proof, and generous `py-32` to `py-40` rhythm. Never use generic equal three-card feature rows. Collapse every grid to one column below 768px without horizontal overflow.

## Signature
A live staffing brief: framed estate imagery carries a quiet availability signal and changing coverage metadata. It makes hospitality staffing feel like a prepared service desk, not a generic agency.

## Motion
Use staged fade-up reveals, parallax image drift, subtle orbital architectural linework, and hover image previews. Animate transform and opacity only. Respect `prefers-reduced-motion`.

## Components
Use hairline rules, nested image frames, outline arrow actions, and row-based service navigation. Use cards only where image elevation or focus helps. Primary conversion action: begin a staffing conversation.

## Avoid
No purple/blue neon, no pure black, no emoji, no Inter, no fake KPI claims, no copied luxury crests, no dense dashboard patterns, no meaningless blobs, no repeated cloned sections, no broken image URLs.
